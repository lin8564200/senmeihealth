# 🏥 醫起溝通 - 台灣政府醫療補助查詢平台

一站式查詢台灣 32 項政府醫療與社福補助資源,涵蓋長照、重大傷病、身心障礙、生育、職災等 10 大類別。

## ✨ 特色

- 🔍 **完整資料庫** — 32 項補助,涵蓋衛福部、健保署、勞保局等 9 個機關
- 🤖 **AI 智慧顧問** — 串接 Dify 對話機器人,即時回答補助相關問題
- 📞 **官方連結直達** — 每項補助附專線與官網,點一下就能申請
- 📱 **響應式設計** — 手機、平板、電腦都好用
- ⚡ **零後端依賴** — 純靜態網站,部署免費

## 🚀 快速開始

### 1. 設定 Dify 網址

打開 `config.js`,把你的 Dify 應用程式網址貼進去:

```javascript
const CONFIG = {
  DIFY_APP_URL: "https://udify.app/chatbot/你的應用程式ID",
  // ...
};
```

### 2. 部署

詳見 [DEPLOY.md](./DEPLOY.md)
